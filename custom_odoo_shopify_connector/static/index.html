How It Works
Up and running in minutes
A guided setup gets you from installation to live syncing quickly — no coding required.
1
Install the Module
Install from the Odoo Apps Store or clone from GitHub. Required Odoo modules (sale_management, stock, account, delivery) are declared as dependencies and install automatically.
2
Create Your Shopify Store Record
Go to Sales › Shopify Stores, click Create, and enter your Shopify store URL, Admin API access token, and configure warehouse and pricelist mappings per store.
3
Register Webhooks in Shopify
Register webhook endpoints for orders/create, refunds/create, and customers in Shopify admin. Paste the webhook secret into Odoo for HMAC-SHA256 signature verification.
4
Configure Cron Jobs & Auto-Workflows
Activate scheduled actions for product export, order import, inventory sync, and price updates. Set auto-workflow rules so orders confirm, invoice, and pay themselves.
5
Monitor Queues & Enjoy Automation
Products, orders, customers, and inventory sync in the background. Failed jobs show clear error messages and can be retried individually — your stores run themselves.
