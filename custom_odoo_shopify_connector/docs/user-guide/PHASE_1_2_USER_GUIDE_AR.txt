══════════════════════════════════════════════════════════════
المرحلة 1 — التأسيس وإعداد المتجر والربط الآمن
══════════════════════════════════════════════════════════════

ما الذي تشمله هذه المرحلة؟
  • ربط متجر Shopify مع Odoo
  • إعداد الـ Webhooks والتحقق الأمني (HMAC)
  • صلاحيات الدخول وقوائم تطبيق Shopify
  • اختبار الاتصال مع واجهة Shopify API
  • منع تكرار نفس الـ Webhook عند إرساله مرتين

──────────────────────────────────────────────────────────────
خطوات الاختبار — المرحلة 1
──────────────────────────────────────────────────────────────

1) افتح: Shopify ← Configuration ← Shopify Stores
2) افتح سجل المتجر (مثل: iZone EG)
3) تحقق من الحقول الأساسية:
     - Name
     - Shop URL (مثال: https://izone-eg.myshopify.com)
     - Access Token
     - Webhook Secret
     - Company
     - Default Warehouse
4) اضغط Test Connection
     النتيجة المتوقعة: نجاح الاتصال بدون أخطاء
5) تأكد من ظهور قوائم تطبيق Shopify:
     Dashboard, Configuration, Products, Customers,
     Orders, Inventory, Queues, Sync Logs
6) افتح: Shopify ← Sync Logs
     النتيجة المتوقعة: وجود سجلات مزامنة يمكن مراجعتها

معايير القبول (المرحلة 1):
  [ ] المتجر متصل بنجاح (Test Connection ناجح)
  [ ] قوائم تطبيق Shopify ظاهرة للمستخدم المصرح له
  [ ] شاشة Sync Logs متاحة للمراجعة

══════════════════════════════════════════════════════════════
المرحلة 2 — مزامنة المنتجات
══════════════════════════════════════════════════════════════

ما الذي تشمله هذه المرحلة؟
  • استيراد المنتجات والمتغيرات (Variants) من Shopify إلى Odoo
  • الربط عبر SKU / الباركود ومعرّف Shopify
  • طابور مزامنة المنتجات (Product Queue)
  • سياسة المنتج غير الموجود في Odoo:
      - إنشاؤه تلقائيًا، أو
      - فشل الاستيراد، أو
      - الاعتماد على الربط اليدوي (Mapping)
    وذلك حسب إعداد المتجر

──────────────────────────────────────────────────────────────
خطوات الاختبار — المرحلة 2
──────────────────────────────────────────────────────────────

أ) استيراد منتج موجود في Shopify

1) في Shopify Admin: اختر منتجًا له SKU واضح
2) في Odoo: Shopify ← Products (أو طابور المنتجات Product Queue)
3) نفّذ مزامنة / استيراد المنتج (حسب الأزرار المتاحة على المتجر أو الطابور)
4) افتح المنتج في Odoo وتحقق من:
     - الاسم
     - SKU
     - السعر (إن وُجد)
     - المتغيرات (Variants) إن وجدت
     - ربط Shopify (Shopify ID / Mapping)

ب) منتج متعدد المتغيرات (Variants)

1) اختر منتجًا في Shopify بعدة خيارات (مقاس / لون ...)
2) زامنه إلى Odoo
3) النتيجة المتوقعة: ظهور المتغيرات بشكل صحيح دون تكرار خاطئ

ج) منتج غير موجود في Odoo (سياسة الإعداد)

1) راجع إعداد المتجر المتعلق بـ:
     Auto Create Product If Not Found
     (أو ما يعادله في إعدادات الطلبات/المنتجات)
2) اختبر حالة منتج غير مربوط:
     - إذا كان الإنشاء التلقائي مفعّلًا: يُنشأ المنتج
     - إذا كان معطّلًا: يفشل الاستيراد/الطلب برسالة واضحة في السجل

د) مراجعة الطابور والسجلات

1) Shopify ← Queues ← Product Queue
2) Shopify ← Sync Logs
3) النتيجة المتوقعة:
     - عناصر الطابور تُعالج (Done / Failed مع سبب)
     - السجلات توضح نجاح أو فشل المزامنة

معايير القبول (المرحلة 2):
  [ ] منتج بسيط يُستورد ويظهر في Odoo بالـ SKU الصحيح
  [ ] منتج بمتغيرات يُستورد بشكل سليم
  [ ] سلوك المنتج غير الموجود يطابق إعداد المتجر
  [ ] يمكن متابعة الحالة من Product Queue و Sync Logs
